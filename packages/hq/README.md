# harv-hq

Companion package to [harv](https://github.com/adrn/harv) for running it on large
samples: pipelining many harv runs, preparing input catalogs, and visualizing the
outputs.

hq lives in the harv repository as a uv workspace member and is released in
lockstep with harv.

```
pip install harv-hq
```

Nothing is implemented yet.
