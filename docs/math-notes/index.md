# Math notes

Longer-form derivations behind parts of `harv` that are not obvious from the code or the
API documentation.
These are written for someone who wants to check the math, or to understand why an
implementation looks the way it does.
These are not tutorials: see the {doc}`tutorials <../tutorials/index>` for worked
examples, and {doc}`../concepts` for ideas that these notes build on.
